De una tabla a la conciliación: el traspaso manual

Dónde acaba la exportación de cadenas y empieza la interpretación financiera, con seis valores reproducibles.

El paso que falta es una decisión, no otro analizador

La muestra Markdown incluye una segunda tabla con saldo inicial, explotación, inversión, financiación, efecto cambiario y cierre. Exportarla produce cadenas. El comprobador espera un objeto JSON con campos definidos, período, moneda, unidad y perímetro. No hay un adaptador automático: una fila llamada “efectivo” no indica de forma fiable qué saldo representa.

Haga reproducible el traspaso

Coloque los tres repositorios como directorios hermanos. Desde md-table-to-csv, exporte la segunda tabla sintética. Revísela antes de preparar un JSON separado en el proyecto de conciliación.

python md_table_csv.py examples/table-sample.md --table 2 --output out/cash-extract.csv
# Revise pares Item/Amount: Opening 100; Operating 35;
# Investing -20; Financing -10; FX -2; Closing 103

Compare los seis valores con cashflow-bridge-check/examples/reconciled.json. Confirme millones de USD y la misma definición de efectivo y equivalentes. Mantenga los signos negativos. Las cadenas con coma decimal de la primera tabla no pertenecen a estos campos: normalice una cifra regional solo después de establecer su convención.

python cashflow_bridge.py examples/reconciled.json --tolerance 0 --json
# calculated_closing 103; difference 0; matches true

Separe la transformación de la conclusión

Anote la tabla número 2, la correspondencia de filas con campos JSON y la unidad de origen. Si cambia un valor, conserve el CSV original y explique el motivo. Evite la opción de prefijos protectores para un traspaso numérico, salvo que retire y documente conscientemente los apóstrofos añadidos.

Un cálculo correcto no demuestra extracción correcta ni idoneidad del perímetro contable. Lo útil es que otra persona pueda repetir la exportación, revisar la correspondencia y obtener la misma aritmética. La sintaxis de cada herramienta está en Table Workshop y Cashflow Fieldnotes; este traspaso es lo que ninguna automatiza.
