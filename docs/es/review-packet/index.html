Práctica reproducible / Cifra & Archivo

Preparar un expediente pequeño que otra persona pueda seguir

Combine imágenes, valores de tabla y un cálculo documentado sin atribuirles procedencia automática.

Un expediente necesita contexto, no más adjuntos

Para una revisión sintética, reúna tres clases de salida: la página que se puede mirar, las cadenas que se pueden recalcular y los supuestos explícitos del cálculo. Una captura sola es incómoda para recalcular; un JSON aislado dificulta saber de dónde salen las cifras.

El PDF y el Markdown incluidos son muestras sintéticas redactadas por separado. No se afirma que uno se haya extraído automáticamente del otro. En un trabajo real, el analista debe comprobar que la página respalda la tabla y documentar la correspondencia.

Prepare los archivos desde cada proyecto

Ejecute cada comando en el repositorio indicado. Para el primero, use el intérprete del entorno virtual del proyecto PDF. Los directorios out son distintos; copie los resultados seleccionados al expediente en lugar de suponer un directorio compartido.

# pdf-page-images
python pdf_page_images.py examples/statement.pdf --pages 1,3 --dpi 144 --format png --output-dir out
# md-table-to-csv
python md_table_csv.py examples/table-sample.md --table 2 --output out/cash-extract.csv
# cashflow-bridge-check
python cashflow_bridge.py examples/reconciled.json --json > result.json

Incluya un manifiesto pequeño

review/
  statement-page-001.png
  statement-page-003.png
  cash-extract.csv
  reconciled.json
  result.json
  readme.txt   # orígenes, páginas, unidad, correspondencia, tolerancia

En el ejemplo de efectivo, result.json debe mostrar cierre calculado 103 y diferencia 0. Anote si utilizó tolerancia 0 o la predeterminada 0.01: decir “correcto” sin umbral oculta un supuesto relevante.

Mantenga la numeración original en los nombres de imagen y sepárela de las etiquetas impresas. No describa el expediente como prueba verificada: una imagen no autentica su fuente y el cálculo solo suma. El permiso para compartir documentos es otra cuestión. Page Image Notes explica el renderizado; el expediente no obtiene una garantía automática de procedencia.
