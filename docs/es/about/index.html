Quién mantiene este cuaderno

Cifra & Archivo es un cuaderno práctico mantenido bajo faigvain-ang. El mismo equipo desarrolla las tres herramientas abiertas asociadas y trabajo relacionado con Eqvero, KolmoPDF y KomoPDF. No somos críticos ajenos que se recomiendan mutuamente.

Nos centramos en el traspaso manual entre formatos y comprobaciones financieras. Eqvero sirve para investigar información pública; KolmoPDF convierte documentos en la nube; KomoPDF permite editar y anotar PDF con prioridad local. Son productos diferentes, con capacidades y tratamiento de datos distintos. Los tres CLI pequeños son proyectos abiertos independientes, no sustitutos de todas las funciones de esos productos.

El código y su historial se alojan en GitHub; este sitio web se publica en Vercel. Se mantiene la relación de mantenimiento compartido indicada arriba.

Cómo funciona este sitio

Los artículos usan datos sintéticos. Este sitio educativo es estático: los comandos se ejecutan en su ordenador, no en el navegador. Las dependencias, si existen, se instalan por separado según el repositorio. Aquí no se cargan archivos ni hay analítica, fuentes externas, scripts CDN, backend o cuentas. Los servicios en la nube relacionados gestionan sus datos por separado.
