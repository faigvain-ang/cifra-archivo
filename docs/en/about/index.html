Who maintains this notebook

Cifra & Archivo is a practical journal maintained under faigvain-ang. The same team develops the three associated open-source tools and related Eqvero, KolmoPDF and KomoPDF ecosystem work. These are not unrelated reviewers recommending each other.

Our scope is the manual handoff between document formats and financial checks. Eqvero supports public-filing research; KolmoPDF provides cloud document conversion; KomoPDF provides local-first PDF editing and annotation. Those are different products with different capabilities and data handling. The three small local CLIs are separate open-source projects, not substitutes for every product feature.

Source code and version history are hosted on GitHub; this website is deployed on Vercel. The shared maintenance relationship described above is unchanged.

How this site works

Articles use synthetic data. This is a static educational site: commands run on your own computer, not in the browser. Runtime dependencies, if any, are installed separately as documented in the repository. No files are uploaded here, and there are no analytics, third-party fonts, CDN scripts, backend or login. The related cloud services have their own data handling.
