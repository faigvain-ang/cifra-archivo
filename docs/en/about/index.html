About Cifra & Archivo

Cifra & Archivo is a practical journal about financial-document workflows: keeping source values intact, making calculations reproducible and preparing review files another person can follow.

Use Eqvero for source-linked public-filing research, KolmoPDF for cloud PDF-to-Markdown conversion, and KomoPDF for PDF editing and annotation. The articles show where these steps fit alongside small local Python tools. Cloud conversion uploads documents; the local examples can be run on synthetic fixtures.
